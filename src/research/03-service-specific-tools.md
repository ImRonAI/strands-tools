## Service-specific tools

Live GitHub snapshot used on 2026-07-26: `strands-telegram@a6e1f27`, `strands-telegram-listener@f227432`, `strands-teams@52771a6`, `strands-hubspot@14fa562`, `strands-deepgram@097f1fe`, `strands-ccxt@7c9a658`, `strands-cloudflare@c12c303`, `strands-vercel@94ea29d`, `strands-sql@70021e1`, `strands-perplexity@eef9a61`, `strands-hackerone@f5c2151`, `strands-agents-spraay@8548a2b`, `strands-ucp@b721ecc`, and `strands-erc8004@00625fc`.

This grouping contains 14 repositories and 22 distinct agent-facing tool surfaces. Counts are based on current exported/decorated tools, not every action or remote API method behind a universal entrypoint. In particular, the dynamic CCXT and Cloudflare clients are one tool each, and the SQL package's class/factory/handler entrypoints all produce the same `sql_database` tool and are counted once.

Source-versus-packaging findings that affect installation:

- `strands-teams` imports `strands_tools_community.templates` while its manifest does not declare `strands-tools-community`; a plain install can therefore fail when a template is selected even though this repository ships its own `strands_teams.templates` package.
- `strands-vercel` imports `strands.tool` but declares only `requests`; its repository also lacks the `strands_vercel/` package path shown by its README import example. The listed install command is the publisher's package name, but the pinned source tree does not establish a working clean-environment import.
- `strands-hackerone` mentions `create_report` in the tool docstring, but the implementation has no `create_report` branch or submission parameters. The row below inventories the implemented read/report/account actions only.
- `strands-erc8004` requires `x402[httpx,evm]` in its base dependencies, yet its README advertises `strands-erc8004[x402]` and the manifest defines no `x402` extra. Its IPFS module also imports `requests`, which is not declared.
- Cryptocurrency trading, batch payments, checkout completion, blockchain writes, and x402 payments can move real assets or create irreversible external side effects. Their rows identify the credentials, funded wallets, and chain configuration needed for those actions.
