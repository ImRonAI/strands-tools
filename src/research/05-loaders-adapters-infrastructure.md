# Tool loaders, adapters, and infrastructure

Live-source inventory of the fixed 15-repository grouping requested on 2026-07-26.

## Scope and counting rules

- I inspected the default branch source, package manifest, README/configuration, and the concrete registration path for every repository. Evidence links are commit-pinned to the exact source inspected.
- A **known name** is a concrete model-visible tool name present in source or deterministically produced from a bundled manifest. An **open-ended family** is a loader whose final names come from a user-supplied provider/spec/file or from runtime synthesis, so no honest finite count exists at repository-inspection time.
- Related tools are occasionally combined into one row when their dependencies and installation context are identical; every name is still written out explicitly.
- Imported official tools are not counted as definitions of the adapter repository. Example-only, test-only, simulated, and README-only claims without an implementation are excluded.
- Tool types use only the allowed taxonomy.

## Exclusions, defects, and production-readiness notes

- `cagataycali/strands-mcp-server/tools/greet.py` is a sample; it is excluded.
- `mikegc-aws/async-agentic-tools`' `research_topic`, `analyze_sentiment`, and `fetch_weather` use artificial delays/simulated results in demos; they are excluded. Imported official `calculator`, `current_time`, file, HTTP, editor, and Tavily tools are also not re-attributed to this repository.
- `mikegc-aws/agentcore-browser-tool/simple/` imports the official `AgentCoreBrowser` unchanged; only the profile subclass is a repository-defined tool.
- `klogins-hash/island-hopper-tools` advertises eight additional classes in its README, but only `ObjectStorageTool` and `DatabaseTool` exist in source. Its advertised `get_tool_functions()` API is also absent.
- `gonzalo123/openapi-toolsmith`'s `list_orders`, `get_order`, and `create_discount_voucher` are generated from the bundled demo spec and are example-only. The generic operation family is inventoried instead.
- `fengclient/strands-sandbox/poc/` contains proof-of-concept scripts, not additional exported tools.
- `Vivek0712/clawskills-strands` creates genuine Strands `Tool` objects for all 52 valid bundled manifests, but its generic shell converter is not equivalent to implementing every documented workflow. In particular, OpenClaw-internal channel/plugin skills need a bridge, requirements are not enforced, and user-provided strings are interpolated into shell commands. Treat it as a high-trust loader, not a hardened execution boundary.
- `vectorize-io/hindsight` has many integrations for other agent frameworks. Repeated semantic/name duplicates are counted once; the 32 core MCP names, three Strands-prefixed names, three Haystack aliases, and nine Claude Code knowledge names are all explicitly present above.
