# Strands Labs and framework-adjacent repositories

Source-first inventory captured 2026-07-26. The inventory is pinned to the repository commits below; install and dependency claims come from each pinned manifest and the implementation named in the Evidence column, not from README marketing tables. A row is included only when the object is a production agent tool, a factory that produces agent tools, a Strands model/tool/hook provider, a runtime/environment entrypoint that directly hosts agent execution, or a production robotics policy selected by an agent-facing tool. Ordinary DTOs, exceptions, renderers, parsers, test models, mock policies, examples, benchmark fixtures, and low-level helper methods are excluded.

For compactness, a single row covers multiple runtime-generated tool names only when one exported provider/factory is the only stable import surface (for example the ROS bridge and coordinator tool factories). Counts in the coverage summary count the concrete generated names, not just the table row.
