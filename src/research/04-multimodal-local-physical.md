Coverage note:

- All 11 requested repositories were live, non-empty, clonable, and had a current PyPI release on 2026-07-26. None was wholly empty or wholly uninstallable.
- The exact count is 56 real `@tool` functions: 1 Transformers, 1 Diffusers, 2 ADB, 8 Sapiens, 13 OmniVoice, 2 MicroGPT, 25 OSMO, and one each for Spot, Strudel, RenderCV, and Inspect.
- `strands-sapiens` is published but not turnkey: its manifest intentionally omits Torch/Torchvision and upstream Sapiens2, and no inference weights are downloaded. Every inference row remains unusable until those are installed manually; pose additionally needs a detector.
- `strands-strudel` has an undeclared hard runtime dependency on `websockets` and attempts a live `pip install` if absent.
- `strands-spot` materially overstates its implementation: only the eight clients in `SERVICE_CLIENTS` are real.
- `strands-adb` core installation is viable, but its docs reference `install_android.sh` and `INSTALL_ANDROID.md`, neither of which exists at the inspected commit. The advertised companion-installer path is therefore unusable.
- `strands-omnivoice` docs say the package does not force a Torch flavor, but live `omnivoice==0.1.5` metadata requires `torch>=2.4` and `torchaudio>=2.4`; installing the desired hardware build first is the reliable route. Its `audio_play` Windows claim is also not implemented by source.
- `strands-rendercv` has a stale MacTeX instruction and an unbounded `rendercv>=1.14` dependency whose current release raises the effective Python floor to 3.12.
- `strands-diffusers[all]` omits the declared `cosmos` extra; install `[cosmos]` explicitly when `cosmos_guardrail` is required.
